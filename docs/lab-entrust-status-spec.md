# 委託單狀態與編號規格

## 1. 目的

本文件定義 `委託測試單` 的狀態切換規則、編號規則，以及正式單與報告號碼的產生方式。

## 2. 適用範圍

- `新增委託單`
- `委託單成立確認 / 目前狀態`
- `正式委託編號`
- `報告號碼`

## 3. 使用者權限

- `目前狀態` 區塊只允許主管顯示。
- 主管判斷條件：`dep_manager = 1`

## 4. 狀態流程

### 4.1 新增委託測試單

新建單據時，只產生臨時編號。

編號格式：

```text
T + YYYYMMDD + - + 三位流水碼
```

例：

```text
T20260715-001
```

### 4.2 收到樣品並確認

當委託單進入收到樣品並確認階段時，需同時符合：

- 主管審核勾選
- 已上傳主管簽名檔
- 已勾選是否有 logo

此階段要產生正式委託編號。

#### 有 logo

```text
YYYYMMDD + - + 三位流水碼
```

例：

```text
20260715-001
```

#### 無 logo

```text
A + YYYYMMDD + - + 三位流水碼
```

例：

```text
A20260715-001
```

### 4.3 檢驗作業

進入檢驗作業後，委託單維持已成立狀態，不另改號。

### 4.4 主管審核完成

主管審核完成後，保留狀態 `2/3` 已產生的正式委託編號，並另外產生報告號碼。

- 正式委託編號：`lab_no`，不得在此步驟改號。
- 客戶報告編號：`report_no`，使用另一組獨立流水號。
- `LQP-14-01.docx` 客戶報告使用 `report_no`。

#### 有 logo

```text
YYYYMM + - + 三位流水碼
```

例：

```text
202607-001
```

#### 無 logo

```text
R + YYYYMMDD + - + 三位流水碼
```

例：

```text
R20260715-001
```

## 5. 流水碼規則

- 流水碼固定為三位數。
- 流水碼以「當月」計算。
- 同一月份內依序遞增。
- 到下個月重新起算。

補充：

- 目前前端已先做月流水計數。
- 若後端也有同名編碼規則，後續需確認是否以後端為準。

## 6. 狀態選單

### 6.1 新單

新建單據時，狀態選單只允許：

- `1).臨時`

### 6.2 既有單

既有單據可切換：

- `1).臨時`
- `2).收到樣品，有logo`
- `3).收到樣品，無logo`
- `4).主管審核完成`

## 7. 操作規則

### 7.1 狀態變更提示

使用者在下拉選單變更狀態時，需立即顯示警語：

```text
儲存後，委託單編號即依新狀態自動產生
```

### 7.2 生效時機

- 狀態可先選，但實際編號以儲存後生效為準。
- 只有在儲存時，系統才真正更新委託編號與相關欄位。

### 7.3 狀態回退

- `2 / 3 / 4` 可互相切換。
- `2 / 3 / 4` 不可退回 `1`。

### 7.4 狀態與 logo 對應

- `2` 對應 `收到樣品，有logo`
- `3` 對應 `收到樣品，無logo`
- `4` 為主管審核完成，不再依 logo 改變狀態

## 8. 主管審核完成時自動處理

當狀態選到 `4).主管審核完成`，儲存時要自動：

- 寫入當天日期到 `已審核日期`
- 帶入 Charles 簽名檔

Charles 簽名檔路徑：

```text
C:\inetpub\wwwroot\newweb2021\pic\itac\Eeid_Charles-ch.jpg
```

- `2 / 3 / 4` 不可退回 `1`。

## 13. 編號與主鍵規則

### 13.1 不變主鍵

每筆委託單都保留不變的系統主鍵：

- `form_id`

說明：

- `form_id` 只用來識別資料本體，不會因狀態變更或編號重算而改變。
- `lab_no` 與 `report_no` 是顯示與作業編號，允許隨流程更新。

### 13.2 編號落庫規則

儲存委託單時，系統會同步寫入：

- `lab_no`
- `report_no`

兩者為不同用途、不同流水號：

- `lab_no` 是委託編號，在狀態 `2/3` 成立後保留。
- `report_no` 是客戶報告編號，只在首次進入狀態 `4` 時產生一次。
- 狀態 `4` 再次儲存或重複匯出時，不得重新產生 `report_no`。

若資料表已存在對應欄位，後端會直接更新該欄位。
同時也會寫入 `values_json`，讓表單內容與目前編號保持一致。

### 13.3 舊編號可搜尋

系統會保留編號歷史索引，讓下列查詢都能找到對應單據：

- 現在的 `lab_no`
- 現在的 `report_no`
- 之前變更過的舊編號

搜尋規則以包含比對為主，也就是使用者輸入一段編號時，可命中對應單據。

### 13.4 查詢依據

委託單維護與相關搜尋功能，應優先以 `form_id` 作為唯一主鍵處理，
再以 `lab_no` / `report_no` / 歷史編號做輔助查詢。

### 13.5 關聯表回查

已確認下列關聯表也可能保留同一筆委託的舊編號或來源編號：

- `dbo.lab_qet_form`
- `dbo.labMechRptMain`

當主表 `dbo.myInstance` 查不到時，系統會回傳相關參考資料，方便後續追查來源。

### 13.6 爐號填寫規則

- 委託單尚未正式成立前，`爐號` 不強制填寫。
- `爐號` 可於後續補登或修改。
- `爐號` 本身為非必填欄位。
